This is currently a placeholder. The 3D HF ray-tracing toolkit — implemented natively in Python
from the Jones & Stephenson ray-tracing formulation, independent of PyLap/PHaRLAP — is under
active development in the PI's private repository. Vetted, publishable components will be ported
into this folder as they mature. The team's earlier open-source 2D toolkit, PyLap (a Python
wrapper for the proprietary PHaRLAP engine), lives separately at
[hamsci/pylap](https://github.com/hamsci/pylap) and remains available as related prior work.
